# python-vacancy-project

## Описание проекта

Этот проект представляет собой консольное приложение для работы с вакансиями с платформы hh.ru. Основные возможности:

- Получение вакансий по ключевому слову.
- Фильтрация вакансий по ключевым словам в описании.
- Сохранение вакансий в JSON-файл.
